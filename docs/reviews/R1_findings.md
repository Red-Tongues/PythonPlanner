# Review R1 — panel findings on M1 code (PR #1, branch `claude/optimistic-allen-ts03d8` @ 98e4780)

Panel: **GH** = GitHub Copilot (read the PR directly) · **MC** = Microsoft Copilot · **GE** = Gemini (Argon); MC and GE received the same code pack. Independent extraction (passes 1–2 analogue); condensed faithfully.

| ID | Sev | Location | Problem | Suggested fix |
|---|---|---|---|---|
| GH1 | high | `db/ddl.py` triggers; `db/guards.py:assert_mutable` | Superseding an unlocked row does not lock it; triggers protect only `locked = true`, and the ORM guard ignores successors, so superseded history can be edited/deleted via raw SQL or direct ORM. | DB rule "has a successor ⇒ immutable" on both dialects + head check in the ORM guard; raw-SQL and ORM tests. |
| GH2 | high | `db/session.py:_sqlite_pragmas` | SQLite `INSERT OR REPLACE` can delete-and-replace a locked packet or append-only row without firing DELETE triggers when `recursive_triggers` is off (default). | `PRAGMA recursive_triggers = ON` on every connection; replacement tests for packets, events, evaluation passes. |
| GH3 | high | `lifecycle.py:is_user_actor / can_transition` | Authority to complete/archive from any state rests on a caller-supplied `user:` string prefix — not proof of user authority. | Non-forgeable actor capability/type passed from a trusted boundary. |
| GH4 | medium | `db/guards.py:_before_flush`; direct ORM writes | Direct ORM edits of unlocked domain rows commit without an audit event; settings change without a version bump. | Force domain mutations through evented write API, or emit event + version centrally in the flush layer; tests. |
| GH5 | medium | migrations `0002`, `0003` `upgrade()` | Applied migrations call live `ddl`/`seed` modules; later edits change what replaying old revisions produces — history not reproducible. | Freeze trigger/view/seed definitions per revision; changes go in new revisions. |
| GH6 | medium | `db/models.py` timestamps; `db/session.py` | SQLite returns naive datetimes, PostgreSQL aware ones — lease/completion comparisons can diverge or fail. | UTC-aware `TypeDecorator`; round-trip/comparison tests on both dialects. |
| GH7 | medium | `db/refs.py:_max_number`, `next_*_ref` | `MAX(ref)+1` allocation races under concurrent ingestion; one transaction fails on the unique constraint. | Atomic counter/sequence allocator; concurrent allocation test on both dialects. |
| GH8 | medium | `0002.downgrade`; `tests/test_schema.py` | Downgrading 0002 drops views but leaves triggers (and PG functions) — DB claims 0001 while enforcing 0002. Untested. | Drop all revision-owned triggers/functions in downgrade; test downgrade + re-upgrade on both dialects. |
| MC1 | high | migrations `0002`/`0003` `upgrade()` | Applied migrations depend on mutable live code (`ddl.install()`, `seed.*`); DBs reaching 0003 at different times can differ. Undermines A4 and deterministic rebuilds. | Freeze DDL/seed per revision. |
| MC2 | high | `db/migrate.py:upgrade()` | Reads `current_revision(engine)` on a second connection inside `engine.begin()` before commit — PostgreSQL can't see the uncommitted `schema_version`; result can be stale/None. | Read revision on the migration connection (or after commit); regression test via the PostgreSQL CI path. |
| MC3 | high | `repository.py` supersede protection; `ddl.py` | Superseded-but-unlocked history is mutable at DB level (engineer acknowledged). Raw SQL can UPDATE/DELETE predecessors. | Triggers rejecting UPDATE/DELETE when a successor exists (projects, objectives, packets); raw-SQL tests both dialects. |
| MC4 | high | `db/seed.py:sync_candidate_fields`; `db/__init__.py:init_db` | Candidate-field registry changes happen outside migration history: same `schema_version` can hold different governed registries depending on which checkout last ran `init-db`. | Registry changes as versioned migrations, or an immutable registry revision/hash referenced by evaluations; `init_db` validates rather than silently mutates. |
| MC5 | high | `db/refs.py` | Same race as GH7; ingestion is a callable kernel operation, so unattended runs hit it. | Transactional counter table (`UPDATE … RETURNING`) with SQLite-compatible strategy; two-writer tests. |
| MC6 | high | `ddl.py` lockable triggers; `models.py` | Lineage invariants not DB-enforced: raw SQL can alter `ref`, `version`, `supersedes_id`, ancestry; successors not validated as `version + 1` with same lineage — forks/re-parenting possible. | Triggers/constraints: successor keeps `ref`, `version = prev + 1`, ancestry immutable, one successor per predecessor. |
| MC7 | medium | `tests/test_schema.py` drift test; migration tests | Drift test compares ORM metadata only; triggers, views and seeds — the governance mechanisms — are unchecked. | Per-revision assertions of expected triggers/views (normalised definitions or hashes) and exact seeds after empty→head. |
| MC8 | medium | `ci.yml` postgres job; `tests/conftest.py` | PostgreSQL CI runs only `-m postgres`; the full suite and CLI path never run on PostgreSQL. | Run the complete suite (incl. init-db → ingest → tree → complete) against PostgreSQL in CI. |
| GE1 | high | `repository.py:~293 supersede_packet` | `TypeError: Packet() got multiple values for keyword argument 'response_contract'` when superseding with a new `response_structure` (explicit kwarg + `**{**carried, **cleaned}`). | Remove the explicit kwarg; take it from the merged dict; add the missing test. |
| GE2 | high | `ddl.py` (both dialects); `guards.py:_before_flush`; `supersede_*` | Same as GH1/MC3: superseded unlocked rows mutable via raw SQL and ORM flush. | Lock old row on supersede, or successor-exists triggers + guard check. |
| GE3 | high | migrations `0002`/`0003` | Live ORM models in 0003: once M2/M3 add columns, replaying 0003 on an empty DB crashes (`UndefinedColumn`). | Freeze DDL/seed in the revisions using local `sa.table(...)` + `op.bulk_insert`. |
| GE4 | medium | `0001_initial_schema.py` constraints; `0002.downgrade` | `uq_evaluation_passes` includes nullable `eval_cycle_id` (NULLs distinct) and omits `packet_id` — duplicates not blocked; downgrade leaves triggers/functions. | Non-null cycle id (or partial unique index) incl. `packet_id`; clean downgrade. |
